# MTG Arena Zone — Limited set reviews

Per-card Limited reviews captured from **[MTG Arena Zone](https://mtgazone.com/)** — one `<SET>.md`
per set. Like [`draftsim/`](../draftsim/), this is a **web-prose** source hand-captured from article
URLs, **outside** the `src/ingest/` YouTube ETL, so the manifest carries `source_urls` + `captured`
instead of video IDs.

MTG Arena Zone publishes one article per colour and rates every card **0–5**. Both halves are used:

- the prose becomes per-card notes here, rendered on the card-reference tiles as **🅰 AZ**;
- the numbers go to `grades/mtgazone_<SET>.json` and render as the **AZ** grade column.

Notes are kept as the reviewer's own words, trimmed to the first sentences of each entry — the point
is the reviewer's reasoning, so they are not paraphrased.

As everywhere in this repo: **17Lands GIH WR is primary.** A set review published before release is
a prediction; where a grade and a win rate disagree, the win rate is the result.
